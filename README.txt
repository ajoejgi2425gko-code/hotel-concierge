ホテル決定後コンシェルジュ

【公開方法】
1. ZIPを解凍します。
2. GitHubで新しいPublicリポジトリを作成します（例：hotel-concierge）。
3. このフォルダ内の7ファイルを、フォルダごとではなくリポジトリ直下にアップロードします。
4. Settings > Pages > Build and deployment で「Deploy from a branch」を選びます。
5. Branchを main、Folderを /(root) にして Save します。
6. 公開後、https://ユーザー名.github.io/hotel-concierge/ でアクセスします。

【仕組み】
このアプリは入力内容からAIへの相談プロンプトを端末内で作成します。AIサービスへ自動送信はしません。生成した文章をコピー・共有し、ChatGPT、Gemini、Microsoft Copilotなどに貼り付けて利用します。

【主な入力項目】
・予約済みホテル名、所在地、公式サイト・予約ページ、部屋・宿泊プラン
・チェックイン／チェックアウト日と時刻（宿泊数は日付から自動計算）
・同行者、子どもの年齢、出発地、交通手段、到着駅・空港
・チェックイン前／チェックアウト後の過ごし方、荷物、送迎・駐車場
・観光の希望、食事、予算、必ず行きたい場所、避けたいこと

【オフライン】
初回アクセス後はアプリ画面とプロンプト生成をオフラインでも利用できる場合があります。AIから回答を得るにはインターネット接続が必要です。Google Fontsはオンライン時のみ読み込まれます。

【ご注意】
荷物預かり、駐車場、送迎、ホテル施設の利用条件、営業時間、料金、交通ダイヤ、予約条件は施設・日程によって異なります。AIの回答だけで確定せず、ホテルや各施設の公式情報で確認してください。
